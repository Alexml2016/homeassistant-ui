# Lighting Manager Panel (v0.2.0)

Визуальная Lovelace-карточка для реального управления освещением, создания и редактирования правил Lighting Manager.

1. Сначала установите интеграцию `custom_components/lighting_manager` и добавьте её в **Настройки → Устройства и службы → Добавить интеграцию**.
2. Добавьте JavaScript-ресурс типа **JavaScript Module**:
   `/local/homeassistant-ui/panels/lighting-manager/lighting-manager.js?v=0.2.0`
3. Добавьте карточку в Lovelace (редактор YAML):

```yaml
type: custom:lighting-manager-panel
```

Для команд WebSocket требуется **учётная запись администратора Home Assistant**. Основные параметры редактируются визуально: режим по расписанию или движению, восход/закат/время, смещение, длительность, дни недели, яркость, задержка выключения, ручной приоритет. JSON доступен в разделе «Расширенные настройки» для сложных случаев. Можно редактировать существующие правила, создавать из шаблонов, удалять и управлять ручным режимом.

Устройства `switch.*` не включаются автоматически — их нужно явно указать в `targets` создаваемого правила. `light.*` обнаруживаются для выбора, но также не управляются, пока для них не создано правило.

**v0.2.0: переход на новый интерфейс.** После `git pull --ff-only` и `bash scripts/deploy.sh` замените URL Lovelace с `?v=0.1.1` на `?v=0.2.0` и полностью перезагрузите вкладку. Python-код в этом обновлении не менялся — перезапуск Home Assistant Core не требуется. Сохранённые правила не преобразуются и не удаляются.

**Устройства:** все существующие `light.*` показываются автоматически. Неуправляемые `switch.*` можно выбрать только явно через список «Добавить переключатель». Переключение лампочки на карточке вызывает сервис `light.turn_on/turn_off` или `switch.turn_on/turn_off`; для управляемого устройства перед переключением устанавливается ручной приоритет. Таймер означает **возврат к автоматике**, а не безусловное выключение по его завершении.

**Правила:** поддерживаются несколько правил на одно устройство и общие правила для нескольких целей. Изменение общего правила влияет на все его целевые устройства. Для работы с полным `targets`-списком используйте «Расширенные настройки (JSON)».

**Автоматические обновления:** статусы правил и ручного режима обновляются через подписку на событие `lighting_manager_updated`, которое сервер публикует при изменении состояния. Открытый JSON-редактор и выбранные устройства при обновлении не сбрасываются. Для перехода с v0.1.x на v0.2.0 обновите только JavaScript через `deploy.sh` и ресурс Lovelace. Перезапуск Core не требуется, если серверная интеграция уже обновлена до версии с событием `lighting_manager_updated`.

**Безопасность:** перед первым включением автоматики проверьте выбранные сущности и длительности. Любое добавленное правило может вызвать команды включения/выключения устройств.
