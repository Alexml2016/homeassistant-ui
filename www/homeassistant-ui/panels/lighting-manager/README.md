# Lighting Manager — визуальная панель v0.2.0

Панель Home Assistant для управления освещением без ручного редактирования JSON.

## Возможности

- Слева обнаруженные `light.*`: поиск, реальные состояния и кнопки включения/выключения.
- Сущности `switch.*` добавляются только явным выбором (не включаются автоматически).
- Справа правила выбранного устройства. Можно создать несколько независимых правил, выбрать любое, изменить или удалить.
- Форма настройки: включение/выключение в заданное время, закат/рассвет с минутными смещениями, длительность, переход через полночь, дни недели, уровень яркости и плавное включение.
- Режим движения: выбор `binary_sensor.*`, период работы, задержка выключения.
- Ручной приоритет до следующего реального события правила или по таймеру.
- Live-статусы правил через событие `lighting_manager_updated`; реальные состояния устройств поступают из Home Assistant.
- Блок «Расширенные настройки (JSON)» остался для редких случаев. При изменении JSON он имеет приоритет над визуальной формой при сохранении.
- Если одно правило относится к нескольким целям, интерфейс предупреждает, что редактирование изменит это правило для всех устройств.

## Обновление с v0.1.1

В SSH-терминале Home Assistant OS:

```bash
cd /config/homeassistant-ui
git switch feature/lighting-manager
git pull --ff-only
bash scripts/deploy.sh --dry-run
bash scripts/deploy.sh
```

В Lovelace → **Настройки → Панели управления → Ресурсы** замените URL на:

```text
/local/homeassistant-ui/panels/lighting-manager/lighting-manager.js?v=0.2.0
```

Тип: **JavaScript Module**. Текущая конфигурация карточки остаётся прежней:

```yaml
type: custom:lighting-manager-panel
grid_options:
  columns: full
```

Рекомендуется панель `sections` с секцией `grid`. При необходимости обновите страницу Windows-браузера через `Ctrl + F5`.

**Только фронтенд обновился относительно v0.1.1**, поэтому перезапуск Home Assistant Core не требуется, если серверная интеграция уже установлена и работает. Если это первая установка Lighting Manager, потребуется установить интеграцию и перезапустить Core.

## Осторожно при испытаниях

Визуальный интерфейс не добавляет правил сам: все существующие правила сохраняются в серверной интеграции. Но созданные и сохранённые правила могут автоматически включать/выключать реальные нагрузки. Сначала испытывайте управление на безопасном светильнике. Кнопки питания отправляют команды напрямую в Home Assistant; для устройства с активным правилом карточка сначала включает ручной приоритет.

Важно: визуальное добавление `switch.*` в список действует в текущем сеансе карточки. Сохранённое правило делает соответствующий переключатель постоянно видимым.

## Ограничения

Первый визуальный интерфейс требует испытаний в настоящем Home Assistant 2026.10.1. Полноценное пакетирование для HACS ещё не выполнено. Старые панели Clock и Garage не затронуты.
