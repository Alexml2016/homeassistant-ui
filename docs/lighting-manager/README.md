## Быстрая установка на Home Assistant OS

Сначала сохраните резервную копию Home Assistant. В SSH-подключении:

```sh
cd /config/homeassistant-ui
git fetch origin
git switch --track origin/feature/lighting-manager
bash scripts/deploy.sh --dry-run
bash scripts/deploy.sh
```

Затем перезапустите Home Assistant Core (не обязательно весь сервер), откройте **Настройки → Устройства и службы → Добавить интеграцию**, найдите **Lighting Manager** и добавьте её.

В настройках Lovelace добавьте JavaScript-ресурс типа **JavaScript Module**:

```text
/local/homeassistant-ui/panels/lighting-manager/lighting-manager.js?v=0.1.1
```

На панели добавьте YAML-карточку:

```yaml
type: custom:lighting-manager-panel
```

Откройте эту панель под администратором. Правила по умолчанию **отсутствуют**, поэтому установка сама по себе не переключает освещение. Сначала создайте пробное правило на безопасном тестовом светильнике.

Для возврата к стабильной ветке:

```sh
cd /config/homeassistant-ui
git switch main
bash scripts/deploy.sh
```

Учтите: скрипт без `--delete` **не удаляет** файлы интеграции при откате. Если требуется убрать прототип полностью, сперва удалите запись интеграции в UI, затем вручную удалите `/config/custom_components/lighting_manager` и файл `/config/www/homeassistant-ui/panels/lighting-manager/lighting-manager.js` после резервного копирования.

## Обновление карточки до v0.1.1

```sh
cd /config/homeassistant-ui
git switch feature/lighting-manager
git pull --ff-only
bash scripts/deploy.sh --dry-run
bash scripts/deploy.sh
```

Перезапустите Home Assistant Core: изменён Python-модуль интеграции, публикующий событие для обновления карточки. В **Настройки → Панели управления → Ресурсы** замените URL с `?v=0.1.0` на `?v=0.1.1`. Затем выполните `Ctrl+F5` в браузере Windows.

В этой версии карточка подписана на событие изменения правил, обновляет статусы без перезагрузки страницы и сохраняет текст, введённый в JSON-редактор.

## Границы прототипа

- Настройка правил доступна через административную WebSocket API и технический JSON-редактор, а не полноценный графический конструктор.
- Периодическая переоценка — раз в 10 секунд; реальные события датчиков обрабатываются сразу.
- Ручное вмешательство определяем по смене состояния/яркости, исключая собственные контексты команд. Некоторые сторонние интеграции могут менять атрибуты неочевидным образом.
- Управляются только явно указанные в правилах устройства; после удаления последнего правила устройство перестаёт управляться, его состояние не меняется автоматически.
- HACS-публикация и автоматическая установка двух частей из монорепозитория **ещё не проверены**; для этой версии используйте `deploy.sh`.
- На реальном сервере автоматическое тестирование и поведение сценариев пока не подтверждены.

Панель не меняет существующие Clock и Garage.
